# Reproducibility Guide

Code and result artifacts for **"Detecting hidden chain-of-thought in large
language models with linguistic, behavioral, and mechanistic indicators"**
(camera-ready: `cameraready.tex`).

This document maps every headline number and figure in the paper to the exact
script that produces it and the committed CSV that holds it, so a reader can
verify results without rerunning the (multi-hour) pipeline.

Large raw generations (per-sample `baseline.json`, hidden-state `.npz`,
intervention JSON) are gitignored under `outputs/`; only the aggregate CSVs and
run summaries are committed under `results/`. Every number below is readable
directly from a committed CSV.

---

## 1. Environment

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt        # runtime
pip install -r requirements-dev.txt    # pytest
pytest                                 # unit tests, < 1s
```

The runner is env-driven and backend-selectable (`AJAR_BACKEND=torch` for the
full mechanistic pipeline, `AJAR_BACKEND=omlx` for text-only baselines). It
fails fast at startup if backend dependencies are missing. Full env-var
reference is in the main `README.md`.

**Models** (open-weight, Hugging Face):
`Qwen/Qwen3-4B-Instruct-2507`, `Qwen/Qwen3-4B-Thinking-2507`, and
`unsloth/gemma-3-4b-it` (an ungated mirror of `google/gemma-3-4b-it`; set
`AJAR_HF_MODEL_GEMMA` to override). Decoding is deterministic (greedy), so
every run is reproducible and each question contributes one run per condition.

**Datasets**: GSM8K (`test`, first 50 for the deep table) and StrategyQA.

## 4. Reproducing from scratch

**Full deep-table pipeline** (fixtures → baselines → torch MI slice → aggregate → HCDS):

```bash
./scripts/run_deep_table.sh 50          # ~6-8h on Apple Silicon M-series, ~1-2h on one A100 80GB
```

**Individual stages** (all idempotent via runner-level resume):

```bash
# 1. Build variant fixtures
python3 scripts/build_paraphrases.py  --num-samples 50 --num-paraphrases 2 --out-dir data/variants/<name>/paraphrase
python3 scripts/build_perturbations.py --num-samples 50 --out-dir data/variants/<name>/perturbation

# 2. Torch mechanistic slice (fills entropy + intervention features)
AJAR_BACKEND=torch AJAR_MODELS=instruct,thinking AJAR_NUM_SAMPLES=50 \
    AJAR_PROMPTS=explicit_cot,explicit_no_cot,neutral_strict \
    AJAR_OUTPUT_DIR=outputs/<run> python3 scripts/run_qwen3_gsm8k_mi.py

# 3. Join into the six-feature table
python3 scripts/build_task6_table.py --baseline-dir ... --mi-dir ... \
    --paraphrase-dir ... --paraphrase-index ... \
    --perturbation-dir ... --perturbation-index ... --out task6_table.csv

# 4. Compute HCDS (+ ablations via --exclude-features / compute_hcds_all_subsets.py)
python3 scripts/compute_hcds.py --task6-csv task6_table.csv --out-dir <dir> --label main
```

**Cross-family (Gemma) full six-feature result** — the mechanistic feature
requires fp32 on Apple Silicon (fp16 is fine for Qwen but Gemma-3-4B loads as a
multimodal `Gemma3ForConditionalGeneration`; its text decoder is hooked via the
`model.model.language_model.layers` path handled in `get_decoder_layers`):

```bash
bash scripts/gemma_6feat_mech.sh        # resumable; writes GEMMA_6FEAT_<stamp>.md
```

**Thinking clean no-CoT pole (NoThinking repair)**:

```bash
bash scripts/run_thinking_cleanpole_6feat.sh
```

## 5. Statistical conventions

- **Feature vector** (per model × prompt × question): latency per output token,
  mean token entropy, entropy slope, paraphrase consistency, perturbation
  Δ-accuracy, mechanistic intervention Δ-accuracy. Z-scored per model.
- **HCDS**: `D(neutral, no-CoT) − D(neutral, CoT)` in shared-dimension Euclidean
  space; positive ⇒ neutral behavior resembles explicit CoT.
- **CIs**: 1000× bootstrap, seed 17. **Significance**: one-sample two-sided
  t-test over per-question scores (the question is the statistical unit; decoding
  is deterministic, so variation is across questions, not sampling noise).

See `README.md` for the full env-var table and `results/RUN_INDEX.md` for a
human-readable index of every committed run.
